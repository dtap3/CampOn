# CampOn
Find campsite at US sites.

CampOn watches recreation.gov campgrounds for openings and emails you
when a site becomes available. Signups come in through a Google Form,
availability checks run on a schedule via GitHub Actions, and alerts go
out through Resend.

See [SETUP.md](SETUP.md) for how to configure the Google Form/Sheet,
Apps Script, and required GitHub secrets.
